Drilling Differential Pressure Calculator

Algorithm & Logic Explanation

This application calculates Differential Pressure (DiffP) typically generated by a Mud Motor or MWD/LWD tools during drilling. The logic proceeds as follows:

  1. Data Ingestion: The ASCII file is parsed looking for a header row. It supports space, tab, or comma delimiters.
  2. State Detection (On/Off Bottom):
    • The app calculates Depth Delta = Hole Depth - Bit Depth.
    • If Depth Delta ≤ Threshold (default 0.5m) AND SPP > Min Threshold, the bit is considered ON BOTTOM.
    • Otherwise, it is OFF BOTTOM.
  3. Baseline Determination (Tare SPP):
    • We need the "Free Rotating" or "Off-Bottom" circulation pressure to determine how much pressure is generated solely by the torque at the bit.
    • The algorithm scans the time-series. When the state is Off-Bottom and pumps are running (SPP > Min Threshold), this value is recorded as the current Baseline SPP.
    • This Baseline SPP is carried forward in time until a new Off-Bottom event occurs. This accounts for changes in flow rate, mud properties, or depth (friction) over time.
  4. Calculation: Diff Pressure = Current SPP - Baseline SPP. (If calculated Diff P is negative, it is clamped to 0).
